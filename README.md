# Portfolio Website

A minimal photography portfolio site with a fixed left sidebar and a masonry image gallery.

## Structure

```
├── index.html          # Home (sample text)
├── about.html          # About (sample text)
├── photography/        # Gallery pages by category
├── images/             # Photo assets (drop images here)
│   ├── architecture/
│   ├── portraits/
│   └── cars/
├── scripts/generate_gallery.py
├── css/styles.css
├── js/gallery.js
└── js/gallery-manifest.json  # Auto-generated image index
```

## Local preview

Open `index.html` in a browser, or run a local server:

```bash
python3 -m http.server 8080
```

Then visit [http://localhost:8080](http://localhost:8080).

After adding or removing photos locally, regenerate the manifest:

```bash
python3 scripts/generate_gallery.py
```

## GitHub Pages deployment

1. Push this repo to GitHub.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, set **Source** to **Deploy from a branch**.
4. Choose the `main` branch and the `/ (root)` folder.
5. Save. The site will be live at `https://<username>.github.io/portfolio-website/`.

The `.nojekyll` file is included so GitHub Pages serves the site as static files without Jekyll processing.

## Adding photos

Drop images into the matching folder — no manual config needed:

| Folder | Gallery page |
|--------|--------------|
| `images/architecture/` | Architecture |
| `images/portraits/` | Portraits |
| `images/cars/` | Cars |

Supported formats: `.jpg`, `.jpeg`, `.png`, `.webp`, `.gif`, `.avif`. Any aspect ratio works — the masonry layout handles it automatically.

The site reads from `js/gallery-manifest.json`, which is generated by scanning those folders. When you push to GitHub, a workflow automatically updates the manifest if you changed anything under `images/`. For local preview, run `python3 scripts/generate_gallery.py` after adding photos.

To add a new gallery category, create a folder under `images/` whose name matches the page (e.g. `images/weddings/` for the Weddings page), add photos, then regenerate the manifest.

## Customization

- Update social links and email in the sidebar footer.
- Edit lorem ipsum text on `index.html` and `about.html`.

## Gallery

The gallery uses CSS multi-column layout (`column-count: 3`) for a masonry-style tile grid. Images of any aspect ratio flow naturally into three equal-width columns with consistent spacing.
